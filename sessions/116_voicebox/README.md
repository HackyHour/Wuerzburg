# Voicebox

Trying out [voicebox](https://github.com/jamiepine/voicebox) for text to speech (TTS).

## Experiment
Experiment with voice cloning using a part of [the infamous Transrapid speech by Edmund Stoiber](https://www.youtube.com/watch?v=2_-ro5GyRZQ).

Tested on the beginning of [Die Verwandlung by Franz Kafka](https://www.gutenberg.org/files/22367/22367-h/22367-h.htm).

> [!CAUTION]
> This is AI generated content and should not be confused with the authentic words by a real person.

# HackyHour Checklists

## After HackyHour

- [ ] Save pad in the `pad_archive` of the repo
- [ ] Update the hackmd pad:
    - [ ] increment the index of the HackyHour
    - [ ] update date and place
    - [ ] remove participants and topic suggestions
    - [ ] update cross-link indices
- [ ] Save the pizza mail in the `pizza` folder of the repo and run `generate_index.sh` there
- [ ] Update the topics in `index.md`
- [ ] (optional) Make or remove special announcements on the website
- [ ] Commit and push all changes in the repo
- [ ] Send messages to announce the next HackyHour in Mattermost and Discord

## Before HackyHour

### A week before
- [ ] Send reminder messages in Mattermost and Discord

### In the morning
- [ ] Send reminder messages in Mattermost and Discord
